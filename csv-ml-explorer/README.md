# CSV ML Explorer

Upload a CSV, get an overview, statistics, charts and a quick machine-learning
baseline (regression or classification). Everything runs locally in the
browser — no server, no data upload.

## Run locally

    npm install
    npm run dev

Open the URL Vite prints (usually http://localhost:5173).

## Build

    npm run build
    npm run preview

## Deploy to GitHub Pages

    npm install --save-dev gh-pages   # already in devDependencies
    npm run deploy

Then enable GitHub Pages in the repo settings, branch `gh-pages`, folder `/ (root)`.
